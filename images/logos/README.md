# Company logos — career timeline

Drop grayscale-friendly logo files here (any solid single-color / full-color
logo works; the timeline applies `filter: grayscale(1)` in CSS). SVG preferred,
PNG fine. Until a file exists, the timeline falls back to a monogram chip.

Expected filenames (referenced in `_index.html`, `.tl-logo__img src`):

| Company          | File                 |
|------------------|----------------------|
| Instinct Science | `instinct.svg`       |
| PwC              | `pwc.svg`            |
| Blue Corona      | `bluecorona.svg`     |
| Inovo            | `inovo.svg`          |

To use a `.png` instead, just change the `src` extension on that company's
`<img class="tl-logo__img">` in `_index.html`.
